# Putting the book up for sale — step by step

Nothing has been uploaded. Every step below is yours to do.

**It is going on itch.io, not DriveThruRPG.** DriveThruRPG will not take this
book: their rules say "We do not accept any product that includes text
generated by AI tools," and they name Claude and ChatGPT on the banned list.
The same policy covers Roll20 and DMs Guild. itch.io allows it as long as you
tick the AI box. The reasoning is written out in `STORE.md`.

The two files you are uploading:

| What | Where it is |
|---|---|
| The book | `store/monstermanual/dist/Axes-and-Aces-Monster-Manual.pdf` |
| The store cover picture | `store/monstermanual/dist/cover-itch.png` |

---

## Part one: put the book up (about 15 minutes)

1. **Sign in to itch.io in Chrome.** If you do not have an account, make one
   at `itch.io/register`. Use the Chrome you normally use, so the password is
   already saved.

2. Go to **`itch.io/game/new`**.

3. **Title:** type `Axes & Aces Monster Manual`

4. **Short description:** copy the one-line tagline from `STORE.md`.

5. **Classification:** choose **Physical game**. (That is itch's name for
   tabletop things. It is not asking you to ship anyone a box.)

6. **AI generation disclosure:** set it to **yes, generated with AI**. Do not
   skip this one. Untagged AI projects get pulled out of browse, and it is the
   condition itch sets for allowing the book at all.

7. **Pricing:** choose **Paid**, and set the price to **$14.99**.

8. **Uploads:** click **Upload files** and pick
   `Axes-and-Aces-Monster-Manual.pdf`. It is about 90 MB, so give it a minute.
   When it finishes, tick **This file will be sold**.

9. **Description:** paste the long description from `STORE.md` into the big
   text box.

10. **Cover image:** upload `cover-itch.png`.

11. **Tags:** paste the tag list from `STORE.md`.

12. Scroll to the bottom and hit **Save**. The page is still private at this
    point — only you can see it.

13. Click **View page** and read it over. When you are happy, go back to Edit,
    change **Visibility** to **Public**, and Save again. It is live.

## Part two: the free Foundry module (optional, about 10 minutes)

This is marketing, not a product. It puts the monsters in front of people who
buy bestiaries.

**It cannot go in Foundry's own module browser.** Foundry changed its rules in
March 2026 and no longer lists packages containing AI art or AI text. So it
goes out as a direct download instead, which still works fine — people paste a
link into Foundry and it installs.

The module folder is `store/monstermanual/foundry/axes-and-aces-monsters/`.

0. **Run the build first** so the module's pictures are in place. From
   `store/monstermanual/`:

   ```bash
   python src/make.py
   ```

   The 168 images are copied in from the game rather than kept in the repo
   twice, so without this the folder has everything except the art.

1. Zip that folder.
2. On the itch page you just made, go to **Edit**, then **Uploads**.
3. Upload the zip. Tick **This file is free** (not "will be sold").
4. Name it `Foundry VTT module (free)`.
5. Save.

**Worth knowing:** the module has not been loaded into a real Foundry yet. It
is built to the right shape but nobody has run it. Before you tell anyone it
works, install it once in your own Foundry and click the import button. If it
breaks, say so and it can be fixed.

---

## Part three: after it is up

1. **Turn on the launch discount.** On the project page: **Edit** →
   **Distribute** → **Sale**. Set **25% off** for one week. itch buyers expect
   this and the sale puts you on the discounts browse page, which is free
   traffic.

2. **Put a link on the game.** A line on AxesAndAces.com pointing at the itch
   page is the cheapest sale you will ever make, because the people playing
   the game already like the monsters.

3. **Do not upload it anywhere else yet.** Gumroad, Payhip and Ko-fi all allow
   it, but none of them bring any buyers of their own. They are only worth
   doing if itch sells and you want a better margin on repeat buyers.

---

## If itch rejects it

They should not — their rules allow this and the AI box is ticked. But if a
human reviewer pushes back, the reply is that the product is a rulebook with
168 original stat blocks, a documented conversion method and written fiction,
and that the AI disclosure field is set. Do not argue the art; argue that it
is a book rather than an art pack.

If they say no anyway, the next stop is a Payhip or Gumroad page linked from
AxesAndAces.com. Neither has any AI rule at all. You lose discovery and keep
the money.
